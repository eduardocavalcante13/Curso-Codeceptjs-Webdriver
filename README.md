# Automação de testes com Codeceptjs + WebDriver

## Testes para login em formato BDD 

### instalar dependencias

```
git clone https://github.com/eduardocavalcante13/Curso-Codeceptjs-Webdriver.git
```

```
Npm install
```

### Rodar testes

```
Npx codeceptjs run --steps
```
